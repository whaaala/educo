# Sections baseline for BATCH LE-15 (2026-10-19)

The bar for ED-4+ (a section gallery at least the leader's size, RULE BEST) and PS-5 (save a section · a global section · a
page from a template). **Counted IN THE PRODUCTS where the user could sign in** (an ordinary Chrome on its own profile;
the automated one was refused by both sites), from public sources otherwise. A number nobody could see is marked, never
guessed. The raw Wix Studio count is `raw-le15-wix-studio-counts.json` beside this file.

**The leader is Wix Studio: 241 ready-made section layouts (139 designed + 102 wireframes) in 24 categories, beside 13
whole design kits.** Under RULE BEST the gallery of ED-4+ (2) is at least that: ≥ 241 sections, covering every one of its
categories, each design in light and dark, live previews (RULE S). Two kinds of choice the leader makes are worth taking
as they are: a **wireframe** (structure only) beside a **designed** version of the same section, and **interactive**
sections (hover, click) as their own family.

## 5. PS-5 comparison: save · global · page-from-template (exact UI words)

| | Webflow | Wix Studio | Framer | Squarespace 7.1 |
|---|---|---|---|---|
| **(a) Save a section to reuse** | Make it a component: right-click › "Create Component", then reuse it by dragging from the **Components** panel on any page of the site [W7]. **Across sites:** a **Library**. Components / Variables panel › "Manage libraries" › "Share with Workspace" › "Share library", then install it on other sites in the same Workspace. No sharing across Workspaces. Beta; plan limits differ between sources (Freelancer / Core: one shared Library) [W3]. | Select › **More Actions** › "**Save as Asset**", which puts it under Add Elements › **Assets** [X1]. **Across sites:** Wix Studio icon › Tools › **Libraries** › create new; holds one set of colours and type plus unlimited assets; "Turn on sharing" for teammates; usable on any Studio site in the workspace [X4]. A user reports that saved assets have **no global control** [X8]. | Make it a component, then Assets panel › ⋯ › "**Add to Library**". This makes it available to all projects in the Workspace. Insert it with ⌘K › "**Browse Library**" [F3]. Alternative: copy the component's URL and paste it into another project. | Hover the section › **heart** icon (Circle partners then pick "This Site"). Reuse via **Add Section › Saved**. Up to **250 per site**. Circle account: 50, or 250 for Gold / Platinum, on any 7.1 site. Enterprise "Team library": 250. Collection sections cannot be saved [S2]. |
| **(b) Global section, edited once, updates everywhere** | The **component** is the global unit: "changes… automatically update every instance" [W7]. Edit by double-clicking or "Edit component". **Detach:** right-click › "**Unlink Instance**". Components panel › "Show instances" finds every use [W7]. Across sites: accept the Library update [W3]. | Select › More Actions › "**Set as Global**", then choose Header / Section / Footer and name it. Place it from the **Global Sections** panel: "Add to page", or "Add to…" › Apply. **Marked:** "global sections… are highlighted green" in Layers, plus a green overlay on hover [X2][X3]. **Detach:** More Actions › "**Detach from Global Section**". The copy becomes a regular section; re-attaching is possible only with Undo straight away. One pinned global section per page. Global breakpoints are separate from the page's [X2]. | The **primary component** updates its instances. Library instances get an "**Update**" in Assets; this can be undone [F3]. **Detach:** "**Unlink Instance**" (it shows when you double-click to edit), which also adds it to Assets. **Layout templates** also act as global header / footer (see c) [F4]. | **No global sections.** A saved section is a "snapshot": "updating the original section won't update the saved version or anywhere else you've added it" [S2]. Each page is independent, with no shared template link. |

**Takeaways for LE-15:**
- Of these four, only Wix has a true *global section* object, and it marks it **green**.
- Webflow and Framer reach the same result with components (Webflow: "Unlink Instance"). Framer adds layout templates with a content slot.
- Squarespace saves only snapshots.
- The one public per-category count anywhere is Webflow's built-in Starter Library: **34 layouts / 9 categories**. Its lack of a CTA, FAQ or contact category is notable.
