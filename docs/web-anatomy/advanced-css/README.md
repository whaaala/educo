# Advanced CSS and Sass — the course, stored (RULE R)

The user's course **"Advanced CSS and Sass: Flexbox, Grid, Animations and More"** (Jonas Schmedtmann), shared as lecture
transcripts from 2026-10-01. Stored once, distilled, never re-read — only extended. Like the design-foundation deck
(`../design-foundation/`), it is a reference the builder is checked against: every technique is recorded with **what the
builder does today** — `HAVE` (a control exists), `PARTIAL` (possible, not the way the course does it, or only by
hand), `GAP` (a page built this way cannot be built). The GAP and PARTIAL lines feed the **layout's definition of done**
(`docs/TASK_TREE.md`), agreed with the user once the course is through.

The builder writes **rem/% and tokens, never px** (rule 16) and builds **through blocks, not hand CSS** — so a technique
the course writes in px or by hand is judged by whether a person can get the same RESULT through the editor.
