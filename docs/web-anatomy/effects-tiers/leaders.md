# Leaders and preset counts per effects family (BATCH RX-5, 2026-10-17)

RULE BEST sets every effects family's Must bar at the best builder for that family. This file names the leader per
family, counts the ready-made presets the leader offers, and lists the axes (adjustable settings) it exposes. It
extends `baseline-builders.md` (BATCH RX-4); tags already defined there (WX-div, SQ-anim, SQ-img, SQ-scroll, SQ-sect,
SQ-art, WF-fx, WX-mouse, FR-pe, FR-text…) are reused and not repeated.

**How a count is stated.** An exact number only when an official page (or the vendor's own published code) lists the
items. Otherwise "unverified" with the best secondary evidence. No number is invented.

**A key new source: Wix's own motion preset library.** Wix publishes `@wix/motion-presets` (MIT, in the `wix/interact`
repo): "Ready-made animation presets for @wix/motion — entrance, scroll, pointer, loop, and background effects"; the README
counts **62 presets: Entrance 19 · Scroll 19 · Ongoing 13 · Mouse 11**, and the source tree adds a **backgroundScroll**
folder (11 `Bg*` presets + `ImageParallax`). The README does not say these are exactly the Studio Inspector's lists, but
every preset name the Studio help shows matches them (Entrance "Reveal" [WX-ent], Loop "Breathe" [WX-loop], Mouse
"Tilt 3D" / "Track" [WX-mouse], background "Parallax / Zoom" [WX-bg]). So the Wix counts below are **the vendor's code
count**: the strongest evidence available, but not a count read off the Studio panel.
