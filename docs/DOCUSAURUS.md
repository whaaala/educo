# Docusaurus — the documentation format (RULE DOC)

Shared by the user on 2026-09-28: https://github.com/facebook/docusaurus (MIT, Meta). Studied and stored here per RULE R.

## What it is

A static-site generator for documentation: Markdown/MDX files in, a React single-page site out — sidebar navigation,
versioning that follows releases, full-site search, i18n, light/dark theming, and deployment to any static host
(GitHub Pages, Netlify, Vercel). Current line: **v3.x** (3.10 at the time of writing; Node 18+). Scaffold:

```
npx create-docusaurus@latest docs-site classic
```

The docs plugin (`@docusaurus/plugin-content-docs`) reads a folder of Markdown (`path`, default `docs`, relative to the
site folder), builds the sidebar from it (`sidebarPath`, or fully autogenerated), and serves it under `routeBasePath`.

## How it lands in this project

- **Source of truth stays where it is:** the user-facing documentation is Markdown in `docs/guide/` — the story
  ([guide/layout-story.md](guide/layout-story.md)) first, the reference guide beside it. Docusaurus RENDERS them; it
  never becomes a second copy to keep in sync.
- **The site lives in `docs-site/`** (its own `package.json`, Docusaurus 3 "classic" preset), with the docs plugin
  pointed at the guide folder and a hand-written sidebar that puts the story first, then the reference, then per-area
  pages as they are added. Set up when the layout work closes, as the first thing after — before templates, components
  or the LLM builder, which all read it.
- **Every finished area adds a page** (RULE L), written in the story's voice: what the person wants, what they do, what
  they see on every screen, why. MDX lets a page embed a live example when words are not enough.
- **Cost:** open source, no service; one more `node_modules` under `docs-site/`, built by `npm run docs:build`, served
  as static files. Not part of the app's gate — its own build check runs when its content changes.
- The published Artifact of a document stays the quick way to read a page today; the Docusaurus site is the durable
  home once it exists.
